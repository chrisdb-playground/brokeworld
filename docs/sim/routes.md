## 🛤️ Core Operational Constraints

Chum World strictly enforces four non-negotiable simulation rules for all route services:

### 1. Recruiter-to-Depot Directionality Rule
- A route service **must strictly originate at a `RECRUITER` node** and **terminate at a `DEPOT` node**.
- Depot-to-Recruiter routes, Depot-to-Depot domestic routes, and Recruiter-to-Recruiter lateral routes are **strictly prohibited**.
```typescript
if (src.kind !== 'RECRUITER' || tgt.kind !== 'DEPOT') {
  throw new Error(`Invariant failed: route ${route.id} must be RECRUITER -> DEPOT only`);
}
```

### 2. Single-Gang Endpoint Ownership Rule
- Both the source `RECRUITER` and the target `DEPOT` must be owned by the route's operating gang:
```typescript
if (src.gangId !== route.gangId || tgt.gangId !== route.gangId) {
  throw new Error(`Invariant failed: route ${route.id} nodes must be owned by the route's gang`);
}
```
Competitor gangs cannot utilize, lease, or route traffic through rival nodes.

### 3. One Route Maximum Between Any Pair of Nodes
- At most **one active route service** may exist between any unique pair of nodes:
```typescript
const pairKey = `${route.sourceId}__${route.targetId}`;
// If count > 1, throw invariant failure
```

### 4. Cross-Border Requirement
- Every physical connection hosting a route service must span across regional boundaries (`isCrossBorder: true`):
  - **Africa ➔ Europe** (crossing the Mediterranean Sea)
  - **Europe ➔ United Kingdom** (crossing the English Channel)

## 📊 Route Attributes & Specifications

| Property | Type | Description | Initial Range / Value |
| :--- | :--- | :--- | :--- |
| **`id`** | `string` | Unique identifier. | e.g. `ROUTE_NEON_AFR_EUR` |
| **`gangId`** | `string` | The syndicate that owns and operates the service. | e.g. `GANG_NEON_GILL` |
| **`connectionId`**| `string` | Underlying cross-border connection link. | e.g. `CONN_NEON_AFR_EUR` |
| **`sourceId`** | `string` | Origin `RECRUITER` node. | Crusher mk3 location |
| **`targetId`** | `string` | Destination `DEPOT` node. | Pressure Tank mk1 location |
| **`mode`** | `'BOAT' \| 'VAN'` | Vehicle mode (Sea crossings default to `BOAT`). | `'BOAT'` |
| **`capacity`** | `number` | Maximum passengers per voyage batch. | `4` to `6` Chums |
| **`price`** | `number` | Passenger ticket fare deducted upon sign-up. | `$270` to `$350` |
| **`durationTicks`**| `number` | Ticks required for vehicle to traverse route. | `50` to `75` ticks (~5–7.5 game days) |
| **`reliability`** | `number` | Base probability of successful arrival. | `0.96` to `0.98` (96%–98%) |
| **`status`** | `'ACTIVE' \| 'CLOSING'` | Operational lifecycle status. | `'ACTIVE'` |
| **`activeVoyageCount`** | `number` | Current concurrent voyages in transit. | Max `2` concurrent |
| **`totalPassengers`** | `number` | Cumulative count of passengers safely delivered. | Increments on voyage success |
| **`revenue`** | `number` | Total ticket revenue generated by this route. | Increments on recruitment |

## 💰 Route Economics & Upkeep

Maintaining an active route network requires substantial recurring capital:

### Recurring Upkeep Formula
During the syndicate AI review cycle (every 60 ticks in [`processGangAI()`](file:///c:/Users/chris/src/playground/chumworld/src/sim/ai.ts#L29)):
$$\text{Upkeep} = \$45\ (\text{base headquarters overhead}) + (\$30 \times \text{number of active routes})$$

If a gang cannot cover its operating debts and treasury falls below $-\$6,000$, bankruptcy triggers and all active routes transition to `'CLOSING'`.

## 🛠️ Autonomous Route Re-establishment

If a gang's route service is interrupted, closed, or missing between its owned recruiters and depots, the syndicate AI attempts automated re-establishment:

1. **Review Frequency**: Evaluated every 60 ticks.
2. **Eligibility Criteria**:
   - Gang must be `ACTIVE`.
   - Gang owns at least one `RECRUITER` and one `DEPOT` without an active connecting route.
   - Gang must possess sufficient liquidity: `gang.cash >= 1500`.
3. **Restoration Cost**: Deducts **`$1,200`** from the syndicate treasury.
4. **Restored Route Parameters**:
   - `mode = 'BOAT'`
   - `capacity = 4`
   - `price = $310`
   - `durationTicks = 65`
   - `reliability = 0.98`
5. **Event Emission**: Dispatches a `ROUTE_OPENED` event and logs the decision into the gang's dossier.
